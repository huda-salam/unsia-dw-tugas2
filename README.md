## Struktur Buku (20 bab)

- **Bab 1–2:** Fondasi — tujuan DW/BI, konsep dimensional, katalog teknik.
- **Bab 3–16:** Studi kasus per industri (Retail, Inventory, Procurement, Order Management, Accounting, CRM, HR, Financial Services, Telco, Transportation, Education, Healthcare, E-Commerce, Insurance).
- **Bab 17–20:** Kimball Lifecycle, proses pemodelan, dan ETL.
